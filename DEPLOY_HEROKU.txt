📋 PASSO A PASSO PARA DEPLOY
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  INSTALAR HEROKU CLI
   Baixe em: https://devcenter.heroku.com/articles/heroku-cli


2️⃣  LOGIN NO HEROKU
   heroku login


3️⃣  CRIAR APLICAÇÃO NO HEROKU
   heroku create nome-do-seu-app
   
   (ou use um nome aleatório):
   heroku create


4️⃣  CONFIGURAR VARIÁVEIS DE AMBIENTE
   heroku config:set NODE_ENV=production
   heroku config:set SESSION_SECRET=$(openssl rand -hex 32)


5️⃣  FAZER DEPLOY
   git add .
   git commit -m "Deploy to Heroku"
   git push heroku main


6️⃣  VERIFICAR STATUS
   heroku logs --tail
   heroku open

   Valor: [o DNS fornecido pelo Heroku]

→ Com header: "Location: https://primorliquidacionbf.shop/index.html"
